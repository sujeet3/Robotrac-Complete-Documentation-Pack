# Robotrac Android UI Design Kit & Field HMI Specification

**Status:** Technical Baseline Specification · **Review Level:** High-Integrity Autonomous Agricultural Machine  
**Environment:** Direct Outdoor Agricultural Sunlight ($10,000\text{ to }100,000\text{ Lux}$ Glare), Dust, Heavy Glove Operation  

---

## 1. Product Personality & Field Ergonomics
Calm, safety-first, zero-fluff, and engineered for high-glare readability. Touch targets must accommodate gloved hands ($> 56\text{ dp}$), and all critical vehicle states must be decipherable at a $1.0\text{ meter}$ glance under direct sunlight.

---

## 2. Visual Tokens & Dual-Theme System

Dark slate themes become unreadable black mirrors in $80,000\text{ lux}$ open sunlight. The system mandates an **Outdoor High-Contrast Day Theme** as the default field operating mode:

### 2.1. Outdoor High-Contrast Day Theme (Default Field Mode)
* **Canvas Background:** `#FFFFFF` (Pure White for maximum LCD brightness)
* **Card Surface:** `#F0F4F8` (Light cool grey container with 2dp solid stroke `#0A1118`)
* **Primary High-Contrast Text:** `#05080A` (Deep solid black, font weight $\ge 600$)
* **Secondary Text:** `#2D3748` (Slate grey, high legibility)
* **Autonomous Active State:** `#007A5A` (Forest Green badge with solid white icon)
* **Warning / Deceleration (Zone 2):** `#D97706` (High-saturation amber)
* **Emergency Stop / Fault (Zone 1):** `#DC2626` (Bright safety red with double stroke)
* **RTK Fixed Badge:** `#0284C7` (Sky blue with bold text "RTK FIXED: 1.8 cm")

### 2.2. Cab / Night Maintenance Theme (Optional Dark Slate)
* **Background:** `#0A0F14` dark carbon
* **Surface:** `#141E28`
* **Text:** `#F8FAFC`

### 2.3. Sizing & Ergonomic Tokens
* **Touch Targets:** Minimum $56\text{ dp}$ for all clickable cards; $72\text{ dp}$ for `PAUSE_MISSION` and `REQUEST_SAFE_STOP`.
* **Typography:** Sans-serif with tabular numerical figures (Inter / Roboto Mono) so coordinates and speed values do not jitter horizontally on screen.
* **Glove Spacing:** $16\text{ to }24\text{ dp}$ padding between adjacent actionable elements to prevent accidental touches.

## 3. High-Priority Field Alarms & Multi-Modal Feedback

Tractor diesel engines emit $85–95\text{ dBA}$ ambient noise. Standard tablet notification pings will never be heard by the operator:
1. **High-Decibel Audio Alarm:**
   * Category 0 / Safe Stop events trigger a continuous pulsating $2.5\text{ kHz}$ alarm tone at maximum Android volume channel (`STREAM_ALARM`), bypassing standard silent/vibrate switches.
2. **Vehicle Acoustic Horn Synchronization:**
   * When an obstacle breaches Zone 1 or Zone 2, the app triggers the tractor's physical $100\text{ dB}$ vehicle horn and flashes a full-screen red warning banner.
3. **Continuous Haptic Bursts:**
   * Tablet haptic motor vibrates in a repeating $500\text{ ms ON} / 200\text{ ms OFF}$ sequence until the operator explicitly acknowledges the alert.

## 4. Required Screens & Specialized Field Components

### 4.1. Overview Screen
* **Connection Mode Badge:** `DIRECT LOCAL WI-FI (Tractor-AP)` vs `CLOUD CELLULAR (MQTT)`.
* **Telemetry Age Indicator:** Large numerical counter `[ 0.1s ]`. If latency exceeds $> 1.0\text{ s}$, pulses amber; if $> 3.0\text{ s}$, overlays a prominent `STALE DATA / LINK LOST` warning watermark.
* **GNSS Satellite Quality:** Satellites in view (e.g., `32 SVs`), fix type (`RTK FIXED`), and terrain roll angle (`Roll: +3.2°`).
* **Persistent Emergency Stop Bar:** Fixed full-width bottom bar with physical tactile separation.

### 4.2. Map & Swath Guidance Screen
* **Vector Layer:** Field boundary, headland turning buffer, and parallel swaths generated by Fields2Cover.
* **Real-Time Tractor Model:** Shows tractor heading, front knuckle steering angle $\delta$, implement footprint, and dynamic ISO 18497 Zone 1/2 perception envelopes.
* **Dynamic Obstacle Markers:** Differentiates between radar-confirmed dynamic targets (red boxes with velocity vectors) and static foliage clutter.

---

## 5. Interaction Safety Rules

* **Two-Step Slide-to-Confirm for Motion:**
  * Mission start and fault clearing require a horizontal **"Slide to Execute"** gesture, eliminating accidental single-tap triggers.
* **Never Mask Hardware State:**
  * The app must never infer that a tractor is stopped simply because network packets ceased arriving. If link is lost, the screen displays: `CONNECTION LOST — VERIFY TRACTOR MANUALLY VIA WIRELESS RF REMOTE`.
* **Independent Authority Warning:**
  * App displays a permanent footer: *"Tablet is supervisory. Primary emergency stop is the certified handheld RF remote."*
